## What's included / 本版内容

- **One-container bilingual console:** embedded responsive Chinese/English Web UI,
  live status, process topology, cell control, presets, subscribers, number binding,
  SMS, calls and network configuration. No separate Node runtime or CDN.
  **单容器双语管理台：** 响应式中英文界面，提供实时状态、进程拓扑、小区控制、预设、
  签约用户、号码绑定、短信、通话及网络配置，无独立 Node 运行时或 CDN。
- **Unified Go API:** versioned `/api/v1`, consistent error envelopes/request IDs,
  explicit preset/custom cell start and idempotent stop. OpenAPI and Postman
  examples accompany the source.
  **统一 Go API：** 规范化接口、错误包络与请求 ID，支持预设/自定义启动及幂等停止，
  随源码提供 OpenAPI 与 Postman 示例。
- **Deployment controls:** Docker bridge mode, Web 8080 by default, opt-in standalone
  API 8082, optional Bearer token, configurable timezone defaulting to Asia/Shanghai,
  persistent business data and explicit container/RF startup.
  **部署控制：** bridge 网络、默认 Web 8080、可选独立 API 8082、可配置 Token，默认
  东八区且支持自定义时区；业务数据持久化，不自动启动容器或射频。
- **SMS and voice tooling:** current-cell-start SMS observations, identity resolution,
  retransmission deduplication, native UCS-2 decoding fixes, number-binding guidance,
  caller-ID handling and 2600/2602 diagnostic routes.
  **短信与语音工具：** 当前小区启动范围的短信记录、身份关联、重传去重、原生 UCS-2
  解码修复、号码绑定提示、主叫号码处理及 2600/2602 测试路由。
- **Release engineering:** verified pinned upstream sources, clean reconstructed seed
  databases, retained third-party notices, corresponding-source artifacts and tested
  image publication to Docker Hub with full-version and 2.1 release-line tags.
  **发布工程：** 固定并核验上游源码、重建干净种子库、保留第三方许可与对应源码包，
  经镜像测试后上传 Docker Hub，区分固定完整版本和 2.1 发布线标签。

## Known limits / 已知限制

Cloud tests are isolated and do not transmit RF. They do not establish handset
GPRS Internet access, radio/USB stability, call quality or end-to-end SMS latency.
These require separate hardware acceptance; this release does not claim those
reported field issues are all resolved. Bundled board firmware provenance and
license limitations are recorded in `docs/THIRD-PARTY.md`.

云端测试不发射射频，不证明手机 GPRS 上网、无线/USB 稳定性、通话质量或端到端短信
时延。这些仍需独立实机验收，不宣称此前所有现场问题均已解决。板卡固件来源与许可
资料限制见第三方说明。

## Upgrade / 升级

Pulling the image does not deploy it or restart the cell. Preserve the external
business-data volume and apply site-specific port/network/token settings through
the documented deployment procedure. No automatic version increment is enabled.

拉取镜像不等于部署或重启小区。升级需保留外部业务卷，并按部署文档应用站点端口、
网络与 Token 配置；不启用自动升版。
