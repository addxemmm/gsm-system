    短信服务码

    101发送 7–10 位号码以签约
    411发送 “info” 查询系统/号码

    短信原生签约长度规则不同于 API 的 2–15 位规则。

    语音诊断号码

    2600回声测试，按 # 结束，最长 60 秒
    2602数字毫瓦测试音，最长 30 秒

    本实验拨号计划无 PSTN 或紧急呼叫保证。
